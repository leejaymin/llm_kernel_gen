Pipeline 레이어의 상태 머신(GENERATE $\to$ EVALUATE $\to$ REFLECT $\to$ OPTIMIZE)이 반복적 생성-평가 루프를 조율하며, Knowledge 레이어의 GPU 사양 및 Triton 패턴이 프롬프트 품질을 향상시킨다. 생성된 커널과 실험 결과는 Storage 레이어에 저장된다.}
